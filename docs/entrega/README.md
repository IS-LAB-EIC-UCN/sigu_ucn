El PDF es material preparado para revisión del equipo, no una constancia de aprobación del profesor. Revisar nombres, formato solicitado y conclusiones propias antes de entregar.

Para regenerar PDF y SVG, instalar ReportLab como herramienta de documentación (`python -m pip install reportlab`) y ejecutar `python scripts/generar_informe.py`. ReportLab no es una dependencia de la aplicación Java.

La presentación se regenera con `python scripts/generar_presentacion.py` y debe ensayarse junto con el guion.
